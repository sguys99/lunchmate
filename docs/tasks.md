## 0. 이 문서 사용법

### 0.1 표기

| 표기 | 뜻 |
| --- | --- |
| `- [ ]` | 미착수 또는 진행 중 |
| `- [x]` | 완료 (완료 기준 충족 후에만. 체크하면 보관본으로 이동) |
| ⛔ **선택 게이트** | Claude Code가 결과물을 보여주고 **멈추는 지점**. 사용자가 고르기 전에는 다음 작업으로 넘어가지 않습니다 |
| ❓ | 사용자 답변이 필요한 작업 |
| `(REC-03)` | 관련 PRD 요구사항 ID |
| `[실기기]` | Claude가 대신 확인할 수 없는 항목. 사용자가 휴대폰으로 확인 후 체크 |

### 0.2 작업 ID와 커밋 규칙

- 작업 ID는 `T{단계}.{번호}` 형식입니다. 예: `T5.12`
- 커밋 메시지에 PRD ID와 작업 ID를 함께 적습니다. 예: `feat(REC-05, T5.18): 다시 뽑기 셔플 모션`
- PRD ID가 없는 작업(준비, 디자인 시스템, 공통 기반 등)은 작업 ID만 적습니다. 예: `design(T1.4): 시안 A Terracotta Table`, `chore(T0.23): Vitest 설정`
- 작업을 끝낸 커밋에서 그 항목을 `- [x]`로 바꿔 `docs/archive/tasks-done.md`의 해당 단계로 옮깁니다. 이 문서에는 미완료 항목만 둡니다. 부모 작업은 하위 작업이 모두 끝날 때까지 남깁니다.
- 완료 메모는 한 줄(날짜, 결정 ID)만 적고 세부는 커밋 본문에 적습니다. 남은 일은 완료 메모에 묻지 말고 새 미완료 항목으로 적습니다.
- 새 작업은 한 줄(약 150자)로 적습니다: `- [ ] T11.1 (REC-07) 목표. 완료 기준: AC-REC-7`. 더 길면 `docs/specs/T11.1.md`에 쓰고 링크합니다.
- 1장은 단계가 끝날 때 한 줄로 갱신합니다.

### 0.3 Claude Code 세션 시작 문장 예시

`@docs/tasks.md` 멘션은 파일 전체를 읽으므로 쓰지 않고, 작업 ID로 지시합니다.

```
T10.12 진행해줘. 시작 전에 관련 PRD ID와 AC를 요약하고,
선택 게이트를 만나면 멈춰서 비교표와 함께 선택을 요청해줘.
```
