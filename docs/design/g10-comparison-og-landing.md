## 2. 번들과 생성 비용

- **앱 JS 번들 증가 0.** OG 이미지는 서버에서 빌드 때 한 번 그리는 정적 PNG(`opengraph-image.tsx`, 요청 값을 읽지 않음)라 클라이언트로 가는 코드가 없습니다. 시안 코드는 `/design-lab` 라우트 핸들러 안에만 있습니다.
- 글꼴은 투표 OG와 같은 KS X 1001 woff 두 개를 재사용합니다(새 파일 없음). B, C의 그릇 그림은 `icon-art.ts` SVG 문자열 재사용.
- PNG 크기(dev 렌더): A 54 KB, A' 49 KB, B 59 KB, C 64 KB. 모두 카카오와 X 권장 한도(수 MB) 안.

## 3. 공통으로 지킨 것

- 1200 x 600(카카오 2:1), 늘 라이트 팔레트, 색은 `sharePalette` 생성 상수만(하드코딩 색 0, `pnpm lint` 통과), 올리브는 이미지마다 한 군데(A, A' 제목 선 / B 그릇 선 / C 고른 카드 테두리).
- 왼쪽 위 단색 그릇 기호 24 + "런치메이트"(D-18 안건 6), 글자는 좌우 88 안쪽(1.91:1 자르기에서 남음).
- 식당 이름 없음. C는 카테고리 이름과 목업 숫자만 씁니다.
- 이미지 안 모든 글자를 서버 OG 글꼴로 그릴 수 있는지 테스트(`art.test.ts`).
- 4상태와 다크 모드: OG 이미지는 정적 한 장이라 로딩, 빈, 오류, 오프라인 상태가 없습니다(해당 없음). 다크는 앱 테마가 아니라 **어두운 채팅방 위 모습**으로 확인했습니다. 모션 없음.
