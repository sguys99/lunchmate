## 2. 안건 (기본안)

1. 합치기 저장: 원본 제보는 그대로, 식당별 합치기 표 `menu_key_merges(place_id, from_key, to_key)`로 집계 때 바꿔 읽음. 이후 같은 옛 이름 제보도 자동으로 합쳐짐, 되돌리기 쉬움
2. 신고 대상: 메뉴 줄(장소 + 비교 키). 관리자도 제보자 닉네임은 보지 않음
3. 신고 저장: 새 테이블 `menu_flags`(본인만 읽기, 1인 1회, 기존 `reports` 하루 30건 한도와 합산). 기존 `review_reports` 제약은 바꾸지 않음
4. 자동 숨김: 서로 다른 3명이면 그 줄을 메뉴판과 홈 카드에서 내리고 검토 대기(MOD-02와 같은 수)
5. 사유: 가격이나 메뉴가 달라요(false), 욕설이나 비방(abuse), 광고나 도배(spam), 기타(other). 칩만, 글 입력 없음
6. 처리 이력: `moderation_actions`에 menu_hide, menu_restore, menu_merge, menu_unmerge, menu_clear 추가(1년 보관, 되돌리기)

## 3. 품질 메모

- 메타 줄 구분자는 얇은 세로선(`Meta`). 줄바꿈되면 다음 줄 첫 칸에 선이 남는 것은 구현 때 `gap`과 `::before`로 정리
- B 390은 목록 → 표로 들어가는 구조, 선택 줄은 데스크톱에서만 sticky
