## 2. 해석 (시안 작성 기준)

- **공통 바탕**: 따뜻한 밝은 배경(크림, 샌드, 오프화이트), 흙빛 단일 포인트, 넓은 여백, 카드 중심, 음식 일러스트
- **정보 밀도**: 카드 한 장에 숫자 3개와 이유 1줄을 넘기지 않습니다. 배지는 최대 2개입니다.
- **일러스트**: 마스코트나 캐릭터가 아니라 음식과 그릇 중심입니다. 시안마다 손그림 질감, 선화, 플랫 중 하나로 다르게 갑니다.
- **모서리** (가정, G1에서 확인): 질문하지 않았지만 따뜻하고 편안한 인상에 맞춰 중간~둥근 편을 기본으로 하고, 시안 C만 작게 갑니다.
- **라이트/다크** (가정, G1에서 확인): 질문하지 않았지만 다크 우선 선호가 없으므로 라이트 우선, 다크는 따뜻한 차콜로 모든 시안에 동등 지원합니다. 시안 D(다크 우선)는 만들지 않습니다.
- **카드 주인공**: 시각적 주인공은 카테고리 일러스트, 정보 위계의 주인공은 식당명과 숫자입니다.
- **기존 문서와 달라지는 점** (반영 완료 10/28): PRD 8.2절과 CLAUDE.md 6.2절의 "토마토 레드 기본안"을 "흙빛 계열 단일 포인트"로, "카드 주인공은 식당명과 숫자"를 위 해석으로, "Pretendard 단일"에 시안 B 제목 세리프 예외를 추가했습니다 (tasks.md T0.2, T0.3).
- **G1과 G3의 구분**: 아래 시안별 카드 구조는 분위기를 보여주는 참고 표현입니다. G1에서는 토큰, 일러스트 화풍, 모션 성격을 고르고 카드 배치는 G3(tasks.md T3.1)에서 확정합니다.

## 4. 레퍼런스 정리 (T1.2)

조사일: 2026-10-28. 각 사이트의 HTML과 CSS를 직접 내려받아 색 변수, 서체, 라운드, 그림자, 전환 값을 확인했습니다. 화면을 렌더링해 본 것은 아니므로 여백 리듬과 모션 체감은 CSS 수치와 일반적인 인상에서 추정한 값입니다(**추정** 표시). oklch 값은 hex에서 어림한 근사치입니다. 스크린샷은 저장하지 않았습니다.

### 4.1 레퍼런스별 관찰

**스타벅스** ([starbucks.com](https://www.starbucks.com), 앱은 설치해 보지 않아 웹 기준, 앱 관련 내용은 추정)

- 색: 배경은 순백이 아닌 따뜻한 중립(`neutral-warm #f3f1ec` ≈ oklch(0.96 0.007 90), `warm-5 #fffbf5`, `warm-50 #f3e9d8` ≈ oklch(0.94 0.025 80)). 포인트는 하우스 그린(`#1e3932` ≈ oklch(0.33 0.04 170)) 하나에 액센트 그린(`#00754a`)을 버튼에만 씁니다. 보조로 크라프트 갈색(`#7c5331` ≈ oklch(0.47 0.07 55))이 있습니다. 포인트 색에 10/30/90% 알파 변형을 두고 배경 틴트로 씁니다.
- 타이포: 본문 SoDo Sans, 제목 일부에 LanderTall(세리프). 큰 헤드라인 한 줄 + 짧은 섹션 제목 + 한 줄 설명 + 텍스트형 행동 링크라는 위계가 반복됩니다.
- 형태: 라운드 8px(카드), 32px(큰 면), 50px(알약 버튼). 카드 그림자는 매우 얕은 2겹(`0 0 .5px #00000024, 0 1px 1px #0000003d`). 전환 0.15~0.3s.
- 이미지: 제품 사진과 채색 일러스트를 큰 블록으로 씁니다. 홈 첫 화면 아래로 프로모션 블록이 4개 연달아 쌓여 밀도가 높습니다.
- 가져올 것: 따뜻한 중립 배경, 단일 포인트 + 알파 틴트 체계, 알약 버튼, 얕은 2겹 그림자, 일러스트가 큰 면을 차지하는 카드.

**아만** ([aman.com](https://www.aman.com))

- 색: 배경 `#f3eee7`(≈ oklch(0.95 0.012 75), 석회빛 샌드), 보조 면 `#e6e2db`, `#ebe8e5`, 선 `#dad9d7`. 본문 `#313131`/`#404040`(순흑 아님), 보조 텍스트 `#82847f`(회녹색, ≈ oklch(0.6 0.008 120)). 채도 있는 색이 거의 없고, 색은 사진이 담당합니다.
- 타이포: 제목 Lyon Display **Light**(가는 세리프), 본문 Whitney 300/400. 본문 13~16px로 작고, 제목은 2rem 안팎으로 크기 대비보다 **굵기를 낮춰 고요함**을 만듭니다. 작은 라벨에 자간 0.05rem 대문자.
- 형태: 라운드 0, 그림자 없음(`box-shadow:none`), 경계는 1px 선(inset)뿐. 전환은 0.4s 색 변화, 0.2s 투명도로 느립니다.
- 여백: 블록 간 2rem 간격이 기본, 카드 섹션 사이가 넓습니다(구체 섹션 간격은 **추정** 64px 이상).
- 가져올 것: 낮은 채도의 샌드 배경, 순흑 대신 짙은 회색 텍스트, 회녹 보조색, 가는 제목 세리프, 그림자 없이 선과 면 톤으로 구분, 느린 페이드.

**Mintlify** ([mintlify.com](https://www.mintlify.com), 문서 사이트 [mintlify.com/docs](https://www.mintlify.com/docs))

- 색: 마케팅 배경 `#f9f6f3`(≈ oklch(0.975 0.006 60), 따뜻한 오프화이트), 문서 사이트 `#fcfcfc`/`#f8f8f8`. 텍스트 `#121715`, 포인트 그린 `#0c8c5e`(문서 `#166E3F`), 보조 액센트 앰버 `#eb9411`. 경계선은 `black/5`(5% 알파) 헤어라인.
- 타이포: Inter 단일 + 라벨용 모노(Paper Mono, Geist Mono). 굵기는 대부분 500(`font-medium`이 압도적), 700은 거의 없음. 헤드라인 34~50px에 자간 -0.02em, 행간 1em, 본문 14~15px(`text-sm`이 가장 많음). 크기 대비로 위계를 만들고 굵기 차이는 작습니다.
- 형태: 라운드 4~6px(칩, 입력), 10~12px(카드), 알약은 배지에만. 그림자는 0.01~0.04 알파의 여러 겹 + 0.5px 안쪽 하이라이트로 거의 보이지 않습니다. 문서 본문 폭은 `max-w-3xl`.
- 이미지: 사진 없이 UI 캡처, 아이콘, 플랫 그래픽. 수치 블록("300M+", "99.99%")을 크게 보여 줍니다.
- 가져올 것: 헤어라인 테두리, 작은 라운드, 500 위주 굵기와 음수 자간 제목, 큰 숫자 블록, 4px 그리드의 정돈된 정렬.

### 4.2 공통점 (런치메이트 원칙으로 옮길 것)

1. **순백, 순흑을 쓰지 않습니다.** 세 곳 모두 배경은 따뜻한 오프화이트~샌드(L 0.95~0.98, 채도 0.005~0.025, hue 60~90), 텍스트는 짙은 회색이나 녹색 기운의 흑색입니다.
2. **포인트는 하나, 쓰는 곳은 좁게.** 브랜드 색은 주 버튼과 선택 상태에만 쓰고 나머지는 알파 틴트나 중립으로 처리합니다.
3. **그림자는 거의 없습니다.** 깊이는 면 톤 차이, 1px(또는 0.5px) 선, 아주 얕은 그림자로 만듭니다.
4. **위계는 타이포 한 축으로.** 스타벅스는 크기, 아만은 가는 굵기, Mintlify는 크기와 자간. 색으로 위계를 만들지 않습니다.
5. **블록 하나에 메시지 하나.** 제목, 한 줄 설명, 행동 하나의 반복이 셋 모두에 있습니다.
6. **전환은 짧고 조용합니다**(0.15~0.4s, 튀는 효과 없음).

### 4.3 피할 점

- 스타벅스: 프로모션 블록 연속 배치, 시즌 배너. 홈은 추천 카드 3장만 둡니다. 녹색 포인트는 흙빛 원칙과 맞지 않으므로 체계만 빌립니다.
- 아만: 사진 의존(우리는 사진이 없음), 라운드 0(편안한 인상과 충돌), 13px 안팎의 작은 본문(모바일 가독성), 0.4s 전환(CLAUDE.md 상한 300ms 초과), 대문자 자간 라벨(한글에 효과 없음).
- Mintlify: 개발자 도구 특유의 차가운 그린과 모노 서체, 코드 블록 미학, 다크 히어로. 모노 서체는 추가하지 않고 `tabular-nums`로 대신합니다.
