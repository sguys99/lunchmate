## 6. 캡처에서 본 품질 메모 (선택과 무관하게 구현 때 고칠 것)

- **로그인 B 약관 부제 줄바꿈**: "시작할 수 있 / 어요."로 단어 중간에서 끊깁니다([캡처](shots/2026-10-30/design-lab-auth-b__390__light__terms.png)). `auth-b.tsx` 약관 부제 `<p>`에 `break-keep`이 빠졌습니다(A와 C는 있음). 시안 코드는 고치지 않았습니다.
- **로그인 A 돌아오기 문구**: "끝나면 이 화면으로 돌아옵니다"에 마침표가 없고 B, C("로그인이 끝나면 이 화면으로 돌아옵니다.")와 다릅니다.
- **온보딩 A 2단계 제목**: "점심 예산과 걷는 거리를 정해 주세요"인데 저녁 예산도 묻습니다. "예산과 걷는 거리"로.
- **온보딩 지도 안내 말풍선**이 지도 목업의 장소 이름(한빛스퀘어)을 가립니다(세 안 공통, 목업 한정이지만 실제 지도에서도 말풍선 위치를 라벨과 겹치지 않게).
- **위치 권한 거부 후에도 현위치 버튼이 남습니다**([C 권한 거부](shots/2026-10-30/design-lab-onboarding-c__390__light__perm-denied.png)). 누르면 브라우저 설정 안내로 이어지게 할지, 숨길지 T4.16에서 정합니다.
- **완료 화면의 "홈에서 이어 보기"**가 A, B에서 390 첫 화면 밖입니다. ONB-05(완료 즉시 첫 추천)라 카드 3장이 보이면 충분하지만, 하단 고정 줄에 두면 한 손 조작에 맞습니다.
- 다크 모드는 세 안 모두 대비와 경계가 정상입니다. 1280은 로그인 C가 우측 지도 칸에 핀 하나만 있어 비어 보입니다.
