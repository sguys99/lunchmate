## 2. 번들 요약 (gzip, 추정)

- 세 안 모두 홈(`/today`)과 랜딩(`/`) 첫 로드 밖입니다. 상세는 카드 "상세"나 지도 마커를 누른 뒤 열리므로 **홈 200 KB 예산 판단 요소가 아닙니다.** 다만 지도 탭은 지도 SDK가 이미 무거워 상세 증가분이 작을수록 좋습니다.
- **A: NumberFlow 약 +5.6 KB**(`RollingNumber`, T2.13 기록값). 나머지는 CSS 전환.
- **B: 0에 가까움.** IntersectionObserver와 CSS만 씁니다.
- **C: 0에 가까움.** 접힘 행(grid-rows 전환)과 더 보기 메뉴를 CSS와 상태 하나로 그렸습니다. 메뉴를 실제 구현에서 Base UI Menu나 Popover로 바꾸면 그만큼 늘어납니다.
- 세 안 모두 시안에서는 시트를 정적 틀로 그렸습니다(지도 바텀시트 자체는 T5.1 지도 시안 몫). 실제 시트는 tasks 2.4절대로 Base UI Drawer를 지도 탭 진입 뒤 지연 로딩합니다. `pnpm build`로 잰 값은 T5.3 선택 뒤 `docs/design/bundle-log.md`에 남깁니다.

## 3. 공통으로 지킨 것

- **카카오 값과 우리 값을 나눴습니다.** 이름, 주소, 전화, 카테고리, 도보 분(좌표)은 카카오에서 오는 세션 메모리 값이고, 가격 중앙값, 👍 수, 태그 빈도, 공개 후기는 `place_id`로 묶인 우리 집계입니다. 그래서 **이름 해석 실패(`?state=error&fail=name`)에서도 집계와 후기는 그대로 보이고**, 제목 자리에 "이름을 불러오지 못했습니다", 도보는 "알 수 없음", 주 버튼은 길찾기 대신 **"카카오맵에서 보기"**(좌표가 없어 `nmap://`을 만들 수 없음)로 바뀝니다. 전화와 네이버 검색 링크도 뺍니다.
- **영업시간과 메뉴를 넣지 않았습니다.** 카카오 로컬 API가 주지 않고 저장도 할 수 없어, "영업시간, 메뉴, 사진은 네이버 플레이스에서 볼 수 있습니다." 한 줄과 네이버 플레이스 링크로 대신합니다(PLACE-04). G1 비교 화면의 상세 시트(`system/b/sheet-screen.tsx`)에는 영업시간과 대표 메뉴가 있었는데, 실제 데이터로는 채울 수 없는 칸입니다.
- **공개 후기만, 닉네임과 방문 월만**(PRD 11.2). 비공개 후기 텍스트는 목업에도 없습니다(AC-FB-2).
- **할인은 표시만.** 세 안 모두 할인 블록에 "사용자가 제보한 정보라 실제와 다를 수 있습니다."(DEAL-02)를 붙였고, B는 "할인 정보는 추천 순서에 쓰지 않습니다."까지 적었습니다(제품 원칙 6).
- **웨이팅**은 공용 배지("12분 전, 조금 기다려요", calm 중립색)를 그대로 씁니다. C는 상세 안에서 바로 웨이팅을 알리는 한 탭 버튼 3개(PLACE-07)도 시험했습니다.
- **추정 가격**은 배지 줄이 아니라 가격 라벨 옆 `EstimateMark`("1인 추정")를 씁니다(D-05 안건 1).
- **표본 적음**(`?data=sparse`, 후기 1건): 세 안 모두 비율 숫자 대신 "후기 모으는 중"과 "아직 1건이라 비율은 3건부터 보여 드립니다."를 보입니다(콜드 스타트 3건 기준).
- **빈 상태**(`?state=empty`, 후기 0건 + 가격 제보 0건): 섹션마다 한 줄 상태 문장, 후기 자리만 "아직 후기가 없습니다 / 다녀오셨다면 첫 후기를 남겨볼까요?" + "후기 쓰기"(테두리, FB-06 P1).
- **오류**(카카오 실패, 재시도 1회 뒤): "식당 정보를 불러오지 못했습니다" + "다시 시도" + "네이버 지도에서 보기"(PRD 12장, T5.24).
- **오프라인**: 빈 화면 대신 세션에 남은 식당 정보를 보이고 위에 "인터넷에 연결되어 있지 않습니다 / 연결 전에 불러온 정보입니다." 한 줄, 후기 자리는 "연결되면 후기를 불러옵니다.", 즐겨찾기와 제보는 비활성(`aria-disabled`).
- **투표에 추가**는 `pollEntry` 플래그처럼 기본 숨김, `?poll=on`으로 자리를 확인합니다(7단계 전).
- 접근성: axe 검사 100건 통과(3안 × 9쿼리 안팎 × 라이트, 다크 × 모바일, 데스크톱, `e2e/a11y.spec.ts`에 등록). 아이콘 버튼은 모두 이름이 있고(`즐겨찾기`, `다른 행동 더 보기`, `상세 닫기`, `오늘 추천으로 돌아가기`), 즐겨찾기는 `aria-pressed` + 상태 안내, 👍 막대, 점 그림, 미터는 `role="img"` + 숫자를 담은 이름. 모든 전환은 `motion-reduce:`로 꺼집니다. 포인트 컬러 면 버튼은 세 안 모두 화면에 하나(B는 본문 버튼과 고정 줄 버튼 중 하나만 보이고 다른 하나는 `inert`).

## 6. 캡처에서 본 품질 메모 (선택과 무관하게 구현 때 고칠 것)

- **A 가격 점 분포**: 같은 값(9,000원 3건)이 위로 쌓이면 가운데 값 눈금선과 겹칩니다. 눈금을 점 뒤 옅은 선으로 내리거나 점 옆으로 비킵니다.
- **B, C 가격 문장**: "8,000원~11,000원"이 줄 끝에서 "8,000원 / ~11,000원"으로 나뉩니다. 범위 조각에 `whitespace-nowrap`.
- **A 숫자 "9 천 원대"**: 숫자와 단위 사이 간격이 홈 카드("9천" + "원대")와 다릅니다. 홈 카드처럼 "천"을 숫자 쪽에 붙입니다(`numberCells` 규칙).
- **C 접힘 행 제목 폭**이 4rem이라 긴 제목은 두 줄이 됩니다(시안에서 "자주 나온 태그"를 "태그"로 줄임).
- **C 더 보기 메뉴**는 시안용 단순 펼침입니다. 실제 구현은 메뉴 패턴(화살표 키 이동, 밖 누르면 닫힘, 닫히면 버튼으로 포커스 복귀)이 필요합니다.
- **시트 틀**은 세 안 모두 정적 그림입니다(끌기, 스냅 없음). 실제 시트 동작은 T5.1 결과를 따릅니다.
- 다크 모드는 세 안 모두 대비와 경계가 정상입니다(axe color-contrast 통과).
