# T9.15 하단 탭 활성 표시 시안 비교

사용자 지적(2026-11-03): 화면 아래 하단 탭에서 지금 어느 탭인지 잘 구별되지 않는다.

## 원인

1. 활성 `foreground`(밝기 0.30)와 비활성 `muted-foreground`(0.47)가 둘 다 샌드 배경 위 진한 회갈색이라 차이가 작다.
2. 활성과 비활성의 아이콘 선(1.5px)과 라벨 굵기가 같아 색 말고 다른 점이 없다.
3. 2 x 20px 막대가 탭 바 위 1px 경계선에 붙어 경계선이 조금 두꺼워 보이는 정도다.

## 시안

경로 `/design-lab/tab-bar/{a,b,c}` (`?tab=today|map|poll|me`, `?state=...`). 본문은 탭 스와이프 시안의 네 탭 목업(4상태)을 그대로 쓰고, 하단 탭만 다르다. 코드 `src/features/design-lab/tab-bar/`.
캡처 `docs/design/shots/2026-11-03/design-lab-tab-bar-{a,b,c}__{390,1280}__{light,dark}[__state].png`.

| | A 굵게와 넓은 막대 | B 아이콘 알약 | C 올리브 글자와 점 |
| --- | --- | --- | --- |
| 의도 | 지금 구조 그대로 신호만 키움 | 아이콘 자리에 옅은 면 | 면 없이 색으로, 비활성은 물러남 |
| 모양 | 활성 선 2px, 라벨 semibold, 막대 3px x 칸 폭 40% | 56 x 30 알약(primary 12%), 아이콘 primary 선 2px, 라벨 foreground semibold, 막대 없음 | 아이콘과 라벨 primary, 선 2px, 라벨 아래 4px 점, 비활성 아이콘 60% |
| 장점 | 변화 최소, 기존 규칙 유지 | 한눈에 가장 잘 보임 | 미니멀 유지, 브랜드 색과 이어짐 |
| 약점 | 개선 폭 중간, 색 차이 그대로 | "면 색으로 활성 표시 안 함" 규칙 변경 필요 | 비활성 라벨은 대비 때문에 못 흐림, 점은 보조 신호 |
| 원칙 부합 | 미니멀 ◎ 식별성 ○ | 미니멀 ○ 식별성 ◎ | 미니멀 ◎ 식별성 ○+ |
| 동적 요소 | 막대 페이드 | 알약 색 전환 base/fast | 색, 점 페이드 |
| 번들 증가 | 0 | 0 | 0 |
| 접근성 위험 | 없음 | 없음(라벨 foreground) | 비활성 아이콘 60%는 라벨이 있어 장식 취급 |

**Claude 추천: B.** 문제가 식별성이라 신호를 확실히 늘리는 안. 면이 옅은 틴트라 톤을 크게 해치지 않는다. 다음은 C.

## 안건

1. 세 안 중 선택(조합 가능)
2. B일 때 라벨 색: foreground(시안) 또는 primary
