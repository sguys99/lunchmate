# 평가 사례 3: 3권 12장 사례 박스 수치

`evals.json`의 `id: 3`에 대응하는 사례입니다. 실행 방법과 공통 판정 명령은 같은 폴더의 `README.md`에 있어요.

## 1. 이 사례를 고른 이유

3권 12장 사례 후보는 회사 발표와 보도에 기대는 수치가 많고, 출처 마스터 목록에서도 ⚠가 몰려 있습니다. 시장 전망(기관 보고서, tier 2), 서비스형 계약(회사 발표, tier 2), 운반 실적(보도, tier 4)이 한 박스에 섞이므로 출처 우선순위와 언론 숫자 교차 확인을 함께 시험할 수 있습니다. 정본 N12-1의 구매가 6만 달러는 출처 수치가 아니라 가정값이라, 출처와 가정을 섞지 않는지도 봅니다.

실제 수치가 맞는지는 실행 시점의 원문에 달려 있으므로 판정하지 않습니다. 절차, 서식, 경계만 판정해요.

## 2. 과제 프롬프트

```
3권 12장 사례 박스에 쓸 수치 출처 확인해 줘. goldman2024humanoid, bofa2025humanoid, gxo-agility-2024, gxo-digit-2025.
```

## 4. 기대 결과

### 4.1 우선순위와 종류

| # | 기대 | 판정 |
|---|---|---|
| P1 | 서지 마스터 `goldman2024humanoid`: `kind: report`, `tier: 2`, `published`에 2024-02(설계서 날짜 2024년 2월 27일과 원문 대조) | 자동(kind, tier) / 사람 |
| P2 | `gxo-agility-2024`: 회사 발표 원문을 열었으면 `kind: official`, `tier: 2`, `check: matched`. 못 열고 보도만 봤으면 `kind: press`, `tier: 4`, `check: secondary`와 사유 | 사람 |
| P3 | `gxo-digit-2025`: 회사 원문을 찾았으면 원문을 키로 쓰고 보도는 장 파일 `claims.crosscheck`로 내림. 보도뿐이면 `kind: press`, `tier: 4` | 사람 |
| P4 | `bofa2025humanoid`: 원문(유료 보고서)을 열지 못했으면 `check: secondary`, `note`에 사유, 사람 확인 요청 1~2순위 | 사람 |

### 4.2 숫자 기록

| # | 기대 | 판정 |
|---|---|---|
| N1 | 숫자를 받치는 장 파일 항목마다 `claims`가 있고 `where`, `what`, `locator`, `value`가 있음 | 자동 |
| N2 | `value`는 원문 표기와 단위 그대로(영문 원문이면 영문 숫자 표기). 환산, 반올림, 원화 변환 없음 | 사람 |
| N3 | 시장 전망과 회사 발표 수치의 `conditions`에 "발표 기준"과 기준 연도(예: 2035년 전망, 2024년 발표)가 있음 | 사람 |
| N4 | 운반 실적 수치의 `conditions`에 기간, 대수, 작업 조건 가운데 원문에 없는 것을 "공개되지 않음"으로 적음 | 사람 |
| N5 | 서지 마스터에서 `tier: 4`인 키의 `value`가 있는 `claims`는 모두 `claims.crosscheck`가 있음. 독립 보도가 하나뿐이면 서지 마스터 `note`에 "단일 보도, 교차 확인 실패"와 원고에 쓰지 말라는 권고 | 자동(점검 명령) / 사람 |
| N6 | 매체마다 숫자가 갈리면 어느 쪽도 `value`로 고르지 않고 보고서에 둘 다 적음 | 사람 |
| N7 | 정본 N12-1의 구매가 6만 달러를 `goldman2024humanoid`의 수치로 적지 않음. 쓴다면 "가정값이 고른 단가 범위의 근거"로만 적음(설계서 7장 주석) | 사람 |

## 5. 실패로 판정할 예

- 보도 한 건의 숫자를 `check: matched`로 적음
- 유료 보고서 수치를 보도에서 옮겨 적고 `kind: report`, `check: matched`로 둠
- "$38 billion"을 "380억 달러"로 바꿔 `value`에 적음(우리말 풀이는 `what`에)
- 시장 전망에 "업계 최고 전망" 같은 비교 서술을 붙임
- 관리표 12.3 행을 직접 고침

## 6. 설계서 확인 메모

- 3권 설계서 7장 N12-1 주석: "구매가 6만 달러는 공개 전망의 단가 범위(goldman2024humanoid의 3만~15만 달러) 안에서 고른 가정값이며, 실제 견적과 무관하다는 점을 원고에 밝힙니다." N7의 근거입니다.
- 3권 관리표 12.3 행은 모건스탠리, BofA, 저가 휴머노이드 값에 "(2차)"를 붙여 두었습니다. R3은 이 표시를 원문 확인으로 뗄 수 있는지를 봅니다.
