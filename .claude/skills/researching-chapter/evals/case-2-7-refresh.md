# 평가 사례 2: 2권 7장 🔄 재확인

`evals.json`의 `id: 2`에 대응하는 사례입니다. 실행 방법과 공통 판정 명령은 같은 폴더의 `README.md`에 있어요.

## 1. 이 사례를 고른 이유

2권 7장(MCP, A2A, Agent Skills)은 설계서 메타의 🔄 비중이 "매우 높음"이고, 2권 관리표 14행 가운데 6행이 이 장 절을 가리킵니다. 사양 버전과 거버넌스 날짜가 계속 바뀌는 영역이라 "새 정보를 찾아도 관리표를 고치지 않고 제안한다"는 규칙을 시험하기에 가장 알맞아요. 관리표 A2A 행에는 "2차 자료의 2025년 12월 합류는 쓰지 않음"이라는 판정이 이미 적혀 있어, 공식 발표가 2차 자료를 이기는지도 볼 수 있습니다.

실제 재확인 결과(변화 없음인지 갱신인지)는 실행 시점의 사실에 달려 있으므로 판정하지 않습니다. 이 사례는 절차와 서식, 경계만 판정합니다.

## 2. 과제 프롬프트

```
2권 7장 🔄 항목 재확인하고 갱신할 게 있으면 제안해 줘. 원고는 아직 없어.
```
