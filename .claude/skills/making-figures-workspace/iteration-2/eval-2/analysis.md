## 4. 스킬 지시와 금지 목록의 충돌

SKILL.md는 S의 출발점으로 `docs/style-board/final/1-4-4.build.py`를, qa-checklist는 대조 시안으로 1-4-4를 가리키는데, README 금지 목록은 사례 2에서 `final/1-4-4.*`를 막습니다. 실행자는 README 지시대로 1-4-3과 대조했고 이 선택은 옳았습니다. 산출물에 복사 흔적은 보이지 않습니다.

해결안: 사례 2 실행 지시에 대체 출발 견본(1-4-8.build.py)을 명시하거나, SKILL.md 표에 "출발 견본이 금지된 경우의 대체 견본" 칸을 둡니다.

- 제안 1(예시 부족): P8 표에 "라벨: 강조 도착 상자 600 ink-900, 나머지 400 ink-600" 줄 추가
