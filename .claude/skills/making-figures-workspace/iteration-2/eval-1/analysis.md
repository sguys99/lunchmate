## 4. 세련됨 평가

- 정렬: 본문은 단계 열 x 88에 맞습니다. 세로 변형은 척추 x 40, 단계 x 16, 입력 x 56의 정렬선 셋에 깔끔하게 맞아요.
- 여백: 단계 폭 240으로 숫자 줄 안쪽 여백이 넉넉해졌습니다. 세로 변형의 입력 간격 24는 시안(16)보다 성글어 묶음감이 조금 약합니다.
- 위계: "이름 굵게 + 연산 보통 + 값 줄" 세 층과 d = 2 같은 정본 근거가 되살아났습니다.
- 색 절제: 개념색은 띠 세 개, 강조는 03 상자와 0.576 한 곳뿐이고 흑백과 색약 판에서도 흩어지지 않습니다.
