## 지시선 점 판단

기대 구도와 맞지 않습니다. 사례 5.2절은 지시선 0개가 기본이고, 둔다면 다른 선과 점을 지나지 않게 정했어요. 점 있는 곡선 위 중간점은 정본 밖 x에 데이터 점이 있는 것처럼 읽힙니다. 실행이 이 위험을 notes.md에 저자 확인으로 남겨 H7(검수 기록의 정직성)은 통과입니다.

## 세련됨 (실패는 아님)

- 가로축 제목 대신 눈금 글자를 "1단계"처럼 쓰면 판을 264까지 쓸 수 있습니다.
- 칩 0.599와 세로 변형의 0.358이 점에서 30~40 떨어져 어느 점의 값인지 연결이 약합니다.
- accent가 선, 칩 2개, 지시선 점의 네 곳에 퍼져 있습니다.
- 세로 변형의 위쪽 여백이 비어 있습니다.

## 스킬 수정 제안

1. chart-guide 3장 지시선 행과 4.2절: 점 있는 선 그래프에서는 지시선 점을 정본 점에만 겁니다. 자리가 없으면 지시선을 빼고, 중간점은 점 없는 곡선에서만 씁니다. figlib leader 경고나 QA 자동 항목도 둡니다.
2. chart-guide 4.1, 4.2, 6장과 patterns.md P15: 맥락 선 계조와 선 종류 규칙을 하나로 맞추고 figlib `context`에 dash와 계조 인자를 엽니다. 1-5-5 처리는 저자가 정합니다.
3. patterns.md P15: 그림 영역 264를 고정하고 단위는 눈금 글자에 붙이는 것을 기본으로 합니다. 견본 판(240)과 원고 판이 다르다는 주의도 적습니다.
4. caption-alt.md 5장 C 행: 숫자 2~4개를 고르는 법을 적고 1-5-5 예시를 정리합니다. README 판정 블록에 alt 소수 개수 검사를 더합니다.
5. chart-guide 4.2절 "점" 행: 정본 x가 붙어 있어도 점은 모두 찍고 라벨만 생략합니다.
