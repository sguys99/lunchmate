### 판단 기록

- 그림의 숫자는 1권 설계서 7장 N4-1, N4-2 정본만 썼습니다. `verify_examples.py`(N4-2 지정)가 모든 단계를 일치로 판정했습니다.
- 메시지는 가중치 0.576 하나로 정했고, 강조색은 03 가중치 상자의 0.576에만 두었습니다.
- 개념 띠는 쿼리, 키, 값 클래스를 써서 6.2절 색상 고정표와 흑백 선 종류를 따랐습니다.
- 출처 줄은 넣지 않았습니다. 계산 방법은 본문이 출처를 밝히고, 숫자는 정본에서 왔기 때문입니다.
- 본문판은 폭 328에서 가장 작은 글자가 7.2 CSS px라서 세로 변형을 따로 만들었습니다.
- Mermaid 세로 변형은 입력 상자가 한 행에 붙어 내용 폭을 넘었기에 figkit으로 다시 그렸어요.
- 토큰 이름은 설계서 E4-3 문구를 따랐고, 그림 1-2-1이 확정되면 분할이 같은지 다시 확인해요.
