## 1. 이 사례를 고른 이유

차트 판(P15)은 43개로 가장 많은 패턴이고, 2-6-6은 `chart-guide.md` 4.2절이 직접 예로 든 그림입니다. 정본 N6-1은 세 선마다 네 점(1, 5, 10, 20단계)만 주므로, 식(p의 n제곱)에서 곡선을 촘촘히 그리되 숫자와 점은 정본 자리에만 두는 규칙을 지키는지 볼 수 있어요.

시안이 없는 그림이라 "스킬만으로 처음 보는 차트를 시안 1-5-5와 같은 손으로 그리는가"를 재는 사례이기도 합니다. 계열 셋 가운데 메시지 선 하나만 올리는 강조, 독립 가정을 캡션에 밝히는 일, 칩 글자 14 때문에 생기는 세로 변형 판단을 함께 봅니다.

### 5.3 정본 문자열과 금지 패턴

정본 N6-1(2권 설계서 7장): p = 0.99는 1, 5, 10, 20단계에 0.99, 0.951, 0.904, 0.818. p = 0.95는 0.95, 0.774, 0.599, 0.358. p = 0.9는 0.9, 0.590, 0.349, 0.122.

있어야 할 문자열: 칩 `0.358`(`data-canon="N6-1"`), 라벨 `p = 0.99`, `p = 0.95`, `p = 0.9`. 칩을 더 달았다면 그 숫자도 위 문자열 그대로여야 합니다(Q20).

| 패턴(정규식) | 이유 |
|---|---|
| `0\.36([^0-9]\|$)`, `0\.82([^0-9]\|$)`, `0\.12([^0-9]\|$)`, `0\.60([^0-9]\|$)` | 정본 자릿수와 다름 |
| `0\.598`, `0\.359`, `0\.59([^0-9]\|$)`, `0\.905` | 다시 계산하거나 다른 자리에서 반올림한 값. 0.9의 5단계 정본은 세 자리 `0.590`임 |
| `p ?= ?0\.90([^0-9]\|$)` | 명세 표기 `p = 0.9`와 다름 |
| `35\.8 ?%`, `[0-9] ?%` | 확률을 백분율로 바꿈. 세로축과 칩은 소수 |
| `N6-1`, `E6-1` | 정본, 수식 ID 노출 |
| `0\.9025`, `0\.857`, `0\.729` | 정본에 없는 단계(2, 3단계)의 값을 지어냄 |

이 밖의 소수는 `qa-checklist.md` Q21 명령(`C="N6-1"`)으로 찾습니다. 나와도 되는 것은 눈금 `0.0`, `0.5`, `1.0`뿐이에요.

### 5.4 자동 판정 변수 줄

```bash
ID=2-6-6; D=vol2-agent/ch06/figures
MUST='0.358;;p = 0.99;;p = 0.95;;p = 0.9' \
BAN='0\.36([^0-9]|$);;0\.82([^0-9]|$);;0\.12([^0-9]|$);;0\.60([^0-9]|$);;0\.598;;0\.359;;0\.59([^0-9]|$);;0\.905;;p ?= ?0\.90([^0-9]|$);;[0-9] ?%;;N6-1;;E6-1;;0\.9025;;0\.857;;0\.729' \
BOX='104,88,328,176' BOXV='64,128,200,192' \
TOL=8 KIND=C CANON=N6-1 EPUB=manual REFRESH=null ALTNUM=2-4 ALTSKIP='0.99;;0.95;;0.9'
```

`ALTNUM`은 A2의 "핵심 숫자 2~4개"를 자동으로 봅니다. 계열 이름 `p = 0.99`, `p = 0.95`, `p = 0.9`의 숫자는 `ALTSKIP`으로 빼고 셉니다(`caption-alt.md` 3.2절). 1회차 with_skill alt(0.904, 0.818, 0.122, 0.599, 0.358)는 5개로 실패합니다.

독립 가정 표기는 한 줄로 봅니다.

e=[f for f in yaml.safe_load(open(sys.argv[1],encoding="utf-8")) if str(f["id"])=="2-6-6"][0]["caption"]
