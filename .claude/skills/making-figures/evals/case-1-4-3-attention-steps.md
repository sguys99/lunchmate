`evals.json`의 `id: 1`에 대응하는 사례입니다. 실행 방법과 공통 판정 명령은 같은 폴더의 `README.md`에 있습니다.

## 1. 이 사례를 고른 이유

1-4-3은 정본 소수가 가장 많이 몰린 M 그림입니다. 1권 N4-2의 네 단계 값 14개가 노드 글자에 그대로 들어가고, 메시지 상자 하나와 굵은 0.576(600)이 강조의 전부예요. 저자 승인 시안(`docs/style-board/final/1-4-3.*`)이 있어 "스킬만 보고 같은 손이 나오는가"를 가장 엄격하게 잴 수 있습니다.

3회차(`iteration-3`)부터 이 사례는 회귀 시험입니다. `references/mermaid-guide.md` 2장에 1-4-3 소스 전체가 본보기로 실렸기 때문이에요. 본문 노드 문구와 강조를 재는 항목(W2, C1, A2, 본문 H3)은 "본보기 재현이 깨지지 않는가"를 봅니다. 판정 항목과 기준은 바꾸지 않았어요. 다만 이 항목들의 통과를 새 M 그림에서의 판단 개선으로 읽지 않습니다. 스스로 판단을 재는 항목은 세로 변형(W3, H5), 검수 기록(F3, H7), `figures.yml` 필드와 `note`(Y1)입니다. 예시에 없는 M 흐름도 사례를 따로 둘지는 저자 결정으로 남겨 두었습니다(`docs/skill-trial-3.8.md` 5.3절 1번).

함께 시험하는 판단은 두 가지입니다. 하나는 Mermaid 본문 640이 경고 없이 나오는지입니다. 다른 하나는 세로 변형에서 Mermaid 360이 넘칠 때 S로 다시 그리는 D3 판단(`choose-type.md` 3.4절, 5장)을 스스로 내리는지예요.


### 5.3 정본 문자열과 금지 패턴

있어야 할 문자열(1권 N4-2, 설계서 7장에서 그대로). 본문과 세로 변형 모두에 있어야 합니다.

| 단계 | 문자열 |
|---|---|
| 입력 | q `[1, 2]`, k `[1, 0]` `[0, 1]` `[1, 1]`, v `[1, 0]` `[0, 1]` `[0.5, 0.5]`, `d = 2` 또는 √2 |
| 01 점수 | `[1, 2, 3]` |
| 02 나누기 | `0.707`, `1.414`, `2.121` |
| 03 가중치 | `0.140`, `0.284`, `0.576` |
| 04 가중합 | `0.428`, `0.572` |

나오면 안 되는 패턴(그림 글자, 대체 텍스트, 캡션에서 0건). 표 안 세로줄은 `\|`로 적었으니 명령에 옮길 때 `|`로 바꿉니다.

| 패턴(정규식) | 이유 |
|---|---|
| `0\.14([^0-9]\|$)`, `0\.28([^0-9]\|$)`, `0\.58([^0-9]\|$)`, `0\.43([^0-9]\|$)`, `0\.57([^0-9]\|$)` | 정본 자릿수(소수 셋째 자리)와 다름 |
| `57\.6`, `28\.4`, `14\.0 ?%` | 정본 소수를 백분율로 바꿈 |
| `N4-2` | 정본 ID는 그림과 캡션에 넣지 않음(style-guide 6.5절) |
| `주문`(주문한 포함), `아직` | N4-2는 토큰 셋(상자가, 안, 왔어요)만 씀 |
| `d_k`, `d ?= ?(64\|128\|512)` | 정본 d = 2 밖의 차원 |

### 5.4 자동 판정 변수 줄

README의 판정 명령 앞에 붙입니다.

```bash
ID=1-4-3; D=vol1-llm/ch04/figures
MUST='[1, 2];;[1, 0];;[0, 1];;[1, 1];;[0.5, 0.5];;[1, 2, 3];;0.707;;1.414;;2.121;;0.140;;0.284;;0.576;;0.428;;0.572' \
BAN='0\.14([^0-9]|$);;0\.28([^0-9]|$);;0\.58([^0-9]|$);;0\.43([^0-9]|$);;0\.57([^0-9]|$);;57\.6;;28\.4;;N4-2;;주문;;아직;;d_k;;d ?= ?(64|128|512)' \
BOX='88,192,240,64;;88,304,240,64;;88,416,240,64;;88,528,240,64;;*,80,*,64;;*,80,*,64;;*,416,*,64' \
```
