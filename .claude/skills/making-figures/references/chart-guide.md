# 차트 그리기 (chart-guide)

C 종류 그림(matplotlib 차트)을 `figlib`로 만드는 작업 안내서입니다. 스크립트 머리를 어떻게 쓰고, 어느 단계에서 어떤 함수를 부르고, 차트 종류마다 무엇을 강조하고 무엇을 빼는지를 정리했습니다. 도구의 정본은 `assets/charts/figlib.py`와 `assets/charts/README.md`, 규칙의 정본은 `docs/style-guide.md`입니다. 이 문서와 값이 다르면 그쪽이 맞고, 이 문서를 고칩니다.

세 권 설계서의 C 그림은 43개입니다(1권 20, 2권 10, 3권 13). 선 그래프와 막대가 대부분이고, 로그 축, 산점도, 범위 막대, 히트맵, 시간 눈금이 몇 개씩 섞여 있어요. 그래서 4장은 설계서에 실제로 나오는 종류만 다룹니다.

## 1. 이 문서의 쓰임과 경계

| 언제 | 볼 곳 |
|---|---|
| 스크립트 파일을 만들 때 | 2장 골격, 8장 예제 |
| 함수를 고를 때 | 3장 함수 지도 |
| 축, 라벨, 칩 자리를 정할 때 | 4장 종류별 서식 |
| 숫자를 넣을 때 | 5장 데이터 규칙 |
| 저장하고 경고를 볼 때 | 7장 |

메시지 한 문장, 강조 하나, 요소 수 상한, 칩 모양 같은 도구 공통 규칙은 `design-rules.md` 2~4장에 있습니다. 여기서는 되풀이하지 않고 차트에서 그 규칙이 어떻게 구현되는지만 씁니다. 종류 선택과 파일 이름, 세로 변형 필요 여부는 `choose-type.md` 4~6장이 맡습니다. 캡션과 대체 텍스트는 `caption-alt.md`, 미리보기 시각 검수는 `qa-checklist.md`에 있어요.

## 2. 스크립트 골격

스크립트 하나가 그림 하나를 만듭니다. 위치는 `vol*/chNN/figures/X.py`이고 출력은 같은 폴더의 `X.svg`, 세로 변형이 있으면 `X.v.svg`입니다(`choose-type.md` 6장).

### 2.1 머리 docstring

머리 docstring은 검수자가 소스를 열었을 때 숫자의 출처를 한눈에 대조하는 자리입니다. style-guide 9.7절은 "메시지 한 문장과 정본 값"을 머리 주석에 적으라고만 정합니다. 아래 칸 구성은 스타일 보드 시안(`docs/style-board/final/1-5-5.py`)을 바탕으로 한 **제안**이에요.

| 칸 | 쓰는 내용 | 예 |
|---|---|---|
| 첫 줄 | `그림 X: 대상 이름.` | `그림 1-8-6: 일반 모델과 추론 모델의 건당 출력 비용.` |
| 명세 | 설계서 그림 명세 행을 그대로 | `1권 설계서 8장 그림 명세 1-8-6(C). ...` |
| 메시지 | `figures.yml`의 `message`와 같은 문장(40자 이하) | `추론 모델의 건당 출력 비용은 ... 약 7.7배입니다` |
| 데이터 | 정본 ID와 결과 칸 문자열, 또는 `references.yml` 키와 논문 그림 번호 | `1권 설계서 7장 N8-3 ...` |
| 가정값 | 가정, 가상 단가인 값과 그림 안 표시 방법. 없으면 `없음` | `두 값 모두 가상 단가` |
| 출처 | `references.yml` 키. 정본만 쓰면 `정본만 씀` | `[liu2023lost]` 꼴 |
| 🔄 | 관리표 행과 기준 월. 아니면 `아님` | `2권 관리표 ○행, 2026년 10월` |
| 실행, 출력 | 저장소 루트 기준 명령과 출력 파일, 캔버스 크기 | `.venv/bin/python vol1-llm/ch08/figures/1-8-6.py` |

### 2.2 데이터는 정본 문자열로

- 정본 결과는 설계서 7장 표의 문자열 그대로 딕셔너리에 둡니다. `float()`로 바꾼 값은 그리기에만 쓰고, 칩 글자는 문자열을 그대로 넘겨요. 0.140의 끝 0과 U+2212 빼기 기호가 살아남습니다(style-guide 6.5절).
- 출처 수치(논문 재구성)는 키 하나에 값 목록을 두고, 바로 위 주석에 `references.yml` 키와 논문 표나 그림 번호를 적습니다.
- 그리기용 중간 점(곡선을 매끄럽게 하는 점)은 정본 식에서 계산합니다. 식의 상수(예: N6-1의 0.076)는 이름 붙인 상수로 두고 주석에 정본 ID를 씁니다(`examples/example-log-n6-1.py`의 `ALPHA`).

### 2.3 경로, 실행, 출력

```python
ROOT = Path(__file__).resolve().parents[3]          # vol*/chNN/figures/ 에서 저장소 루트
sys.path.insert(0, str(ROOT / "assets/charts"))
import figlib as fl  # noqa: E402
```

```bash
.venv/bin/python vol1-llm/ch08/figures/1-8-6.py              # SVG만
.venv/bin/python vol1-llm/ch08/figures/1-8-6.py 미리보기폴더    # SVG + 컬러, 흑백, 폭 328 PNG
```

- 출력은 세 가지입니다. 본문 `X.svg`(640 또는 800)와 세로 변형 `X.v.svg`(360~400, 필요할 때만)가 있어요. 미리보기 PNG는 `X.png`, `X.gray.png`, `X.w328.png` 세 장입니다.
- 세로 변형은 같은 스크립트가 함께 만듭니다. 시안 `final/1-5-5.py`처럼 `LAYOUT` 딕셔너리의 `body`, `v` 항목에 캔버스, 축 영역, 칩 방향, 지시선 위치만 달리 적습니다. 그리고 `build(variant)`를 두 번 부릅니다. 데이터는 한 곳에만 둡니다.
- 미리보기 폴더의 위치와 이름 규칙은 `qa-checklist.md`를 따릅니다.

## 3. figlib 함수 지도

함수는 부르는 순서가 중요합니다. 칩, 직접 라벨, 지시선은 데이터 좌표를 캔버스 px로 바꿔 그리기 때문에 축 범위가 먼저 확정돼야 해요.

| 단계 | 함수 | 언제, 무엇을 |
|---|---|---|
| 1 캔버스 | `figure(width, height, plot)` | `"body"`(640), `"spread"`(800), 360~400 정수. 높이는 style-guide 5.1절 단계만 받음. `plot`은 축 영역 (왼, 위, 오른, 아래) px |
| 1 머리줄 | `header(fig, "그림 X", 대상)` | 대상 16자 이하. 정본 ID가 들어가면 오류 |
| 2 축 제목 | `y_title(ax, 글)`, `x_title(ax, 글)` | 단위는 여기서 한 번만. 세로축 제목은 축 위에 가로로. `x_title`은 480 판처럼 영역 아래에 자리가 남을 때만(320 판은 4.2절 "축 제목" 행) |
| 2 범주 축 | `categories(ax, 라벨, pad)` | 막대와 범주 x를 0, 1, 2 ...에 두고 좌우 여백. 6개 초과면 경고 |
| 2 축 범위 | `ax.set_xlim`, `ax.set_ylim`, `ax.set_yticks` | matplotlib 그대로. 눈금 3~5개 |
| 2 로그 축 | `log_axis(ax, which, fmt, ticks, lim)` | `fmt`는 `plain`, `kr`, `pow`(4.3절) |
| 2 눈금 서식 | `fixed_decimals(ax, which, n)` | 한 축의 소수 자릿수를 맞춤(0.00, 0.02, 0.04) |
| 3 계열 | `line(ax, x, y, role, token, rank)` | `message`(accent 1.5, 채운 점), `context`(ink-400 1px 실선, 흰 속 점), `ink`, `token="c-key"`(개념색과 흑백 파선). 맥락 선이 둘이면 `rank=1`(ink-600 파선), `rank=2`(ink-400 1.5px 점선)로 가름(4.2절) |
| 3 막대, 점 | `ax.bar`, `ax.barh`, `ax.scatter` | figlib 도우미 없음. 색은 `color(토큰)`, `linewidth=0` |
| 4 칩 | `chip(ax, x, y, 글, unit, accent, canon, side, target_r)` | 정본 결과에만. 반환한 상자를 라벨의 `after`로 |
| 4 선 끝 라벨 | `direct_labels(ax, [dict(line, text, after)])` | 선 그래프의 범례 대신. 24 미만으로 붙으면 밀고 꺾임선 |
| 4 지시선 | `leader(ax, xy, 글, direction, length, message)` | 메시지 1개, 보조 2개까지. 점 있는 선 그래프에서는 점을 데이터 점 위에만 찍음(밖이면 경고). 점 없는 곡선의 중간점만 `on_line(선, x)` |
| 5 저장 | `save(fig, 경로, title, desc, preview_dir)` | 후처리와 `lint`. 문제가 있으면 예외 |
| 5 따로 검사 | `figlib.py lint 파일...`, `figlib.py preview 파일 폴더` | 명령줄 |
| 보조 | `color`, `bw`, `px`, `to_px`, `fmt_number`, `fmt_kr`, `fmt_pow`, `text_width` | 토큰 색, 흑백 선 종류, px 변환, 4.5절 숫자 표기, 글자 폭 |

figlib에는 막대, 점, 보통 글자용 공개 도우미가 없습니다. 그래서 막대는 matplotlib을 직접 부릅니다. 칩 옆 "가정" 같은 보통 글자는 `fig.text`에 `transform=fl.px(fig)`, 크기 14, ink-600을 줘서 둡니다(8장 예제).

## 4. 차트 종류별 서식

### 4.1 공통 축 규칙

`book.mplstyle`이 이미 적용하는 값입니다. 손으로 덮어쓰지 않아요.

| 요소 | 값 | 근거 |
|---|---|---|
| 축선 | 아래 축선만 1px ink-900. 위, 오른쪽, 왼쪽 축선 없음 | style-guide 5.13, 6.4 |
| 세로축 눈금 | 눈금 표시 없이 숫자만(ink-500, 14) | 같음 |
| 격자선 | 가로 보조선만 1px ink-300 | 같음 |
| 계열 순환 | ink-900, ink-600, ink-400 + 실선, 파선, 점선. `line(role=...)`을 쓰면 첫 칸을 메시지 계열 accent가 맡고, 맥락 선은 `rank`로 다음 칸을 씀(4.2절) | 6.2, 3.4, 9.7 |
| 범례 | 꺼 둠. style-guide 6.4절 네 경우에만 직접 부름 | 6.4 |

눈금은 3~5개로 줄이고 끝 눈금을 데이터 범위 바로 바깥의 둥근 값에 둡니다(0, 0.5, 1.0). 눈금이 적을수록 보조선도 적어 데이터가 앞으로 나와요. 이 개수 기준은 시안 두 장에서 가져온 **제안**입니다.

### 4.2 선 그래프(곡선)

해당 그림: 1-1-4, 1-5-3, 1-5-5, 1-6-4, 1-7-3, 1-8-2, 1-10-2, 2-6-6, 2-11-2, 3-2-5, 3-4-4, 3-11-4 등.

| 항목 | 서식 |
|---|---|
| 강조 | 메시지 계열 1개만 `role="message"`. 나머지는 `context`. 같은 축 개념 비교(예: 키와 값)일 때만 `token` |
| 맥락 선 | 하나면 `role="context"`(ink-400 1px 실선). 둘이면 흑백에서 선 종류로 갈라야 하므로(D1, 3.4절) `rank=1`은 ink-600 1px 파선(5 3), `rank=2`는 ink-400 1.5px 점선(0.1 4.2, 둥근 끝, 3.4절 점선 굵기 하한). 메시지 선에 가깝거나 비교의 짝이 되는 선이 1. 모든 선에 직접 라벨을 함께 둠 |
| 계열 수 | 3개 이하(본문 폭). 2-6-6의 p 세 줄은 상한 안. 3-11-4의 네 줄은 펼침 폭 800(상한 4)이거나 한 줄을 덜어 냄 |
| 직접 라벨 | 선 오른쪽 끝, `direct_labels`. 축 영역 오른쪽에 라벨 폭만큼 자리를 남김(`plot` 오른쪽 값) |
| 칩 | 메시지가 기대는 정본 결과 1~2개. 끝점 칩이면 라벨을 `after=칩상자`로 칩 뒤에 |
| 점 | 정본이 정한 x에만 점. 식에서 그린 매끄러운 곡선은 `marker=False`로 그리고, 정본 점만 따로 `line`을 겹침. 정본 x의 점은 몰려 있어도 모두 찍고, 붐비면 숫자 라벨만 생략함 |
| 축 제목 | 세로축은 무엇과 단위("확률", "손실(처음 = 1)"). 320 판은 가로축 제목 자리를 만들려고 그림 영역 아래 끝 264를 올리지 않음(P15). 가로축이 무엇인지는 눈금 글자에 담는 것이 기본안("T = 0.5", 1-5-5). "5단계"처럼 눈금에 단위를 붙이는 것은 style-guide 6.5절 단위 규칙과 겹쳐 저자 확인 대기이고, 승인 전에는 둘 중 어느 쪽을 골랐는지 `note`에 적고, 캡션 읽는 법과 alt에서도 가로축을 밝힘 |
| 지시선 | 점 있는 선 그래프에서는 지시선 점을 정본 점 위에만 둠. 정본 점 옆에 문장 자리가 없으면 지시선을 빼고 칩과 캡션으로 메시지를 전함. 지시선을 빼도 세로 변형 판과 그림 영역(1-5-5.v 실측 360 × 368, y 128~320)은 그대로 두고, 영역 위 빈 띠는 여백으로 남김(`patterns.md` P15). 정본 밖 x의 중간점(`on_line`)은 점 없는 곡선에서만 씀. 점 있는 선 위의 중간점은 정본 밖 데이터 점처럼 읽힘 |
| 하지 말 것 | 곡선 아래 면 채우기, 선마다 다른 개념색, 마커 모양으로 계열 구분, 범례 |

2-6-6처럼 정본이 점 몇 개(1, 5, 10, 20단계)만 주는 곡선은 정본 식(p의 n제곱)에서 점을 촘촘히 계산해 매끄러운 선을 그리고, 칩은 정본 점에만 답니다. 칩은 가리키는 점 바로 옆(`chip`의 `side` 기본 간격)에 두어, 점에서 떨어져 다른 점의 값처럼 읽히지 않게 합니다. 기준은 둘입니다. 칩 상자의 가장 가까운 변에서 가리키는 점 중심까지 16 이하(기본 `gap` 8이면 11.5~12)이고, 칩에 가장 가까운 데이터 점이 가리키는 점이어야 합니다. `chip`은 둘 중 하나라도 어기면 경고를 냅니다. 대각 방향(`above-right` 등)은 거리 기준을 지켜도 칩 가운데가 점에서 멀어 보이니, 선이 지나가지 않는 쪽이면 `right`나 `above`를 먼저 씁니다.

판의 치수는 `patterns.md` P15(1-5-5 실측)를 씁니다. `examples/example-log-n6-1.py`는 함수 견본이라 판이 다르고(`plot=(88, 88, 560, 240)`, 가로축 제목 있음) 원고 그림에 복사하지 않습니다.

시안 1-5-5는 맥락 선 둘을 모두 ink-400 실선으로 그렸습니다. 위 "맥락 선" 행은 D1(흑백은 선 종류로 구분)에 맞춰 정한 규칙이고, 시안과의 차이는 저자 확인 대상입니다(`docs/skill-trial-3.8.md` 4장). 3-11-4는 2권 그림 2-11-2와 같은 축을 쓰라는 명세가 있으니 축 범위와 눈금을 그 스크립트에서 가져와요.

### 4.3 로그 축

해당 그림: 1-4-8(옛 1-4-7, 4장 그림 번호 이동), 1-6-2, 2-10-5(🔄), 3-1-2, 3-6-5, 3-10-3.

| `fmt` | 눈금 | 고르는 기준 |
|---|---|---|
| `plain` | 1, 10, 100, 1,000 | 배수, 1만 미만 범위. 기본값 |
| `kr` | 100만, 1억, 1조 | 본문이 한글 단위로 부르는 셈. 1-4-8(N4-3: 100만, 약 164억), 3-1-2(1.4조, 18억) |
| `pow` | 10², 10²³ | 단위 없이 아주 넓은 범위(FLOPs) |

- 한 축에서 서식을 섞지 않습니다. `ticks`로 주 눈금을 3~4개만 남기고, 보조 눈금 숫자는 쓰지 않아요(`minor=False` 기본).
- 점이 6개 이하인 로그 가로축은 눈금을 데이터 점 자리에 둡니다(`log_axis(ax, "x", ticks=[점 x 값])`). 10배 간격 눈금(1,000, 10,000, 100,000)을 두면 2,000, 8,000, 128,000 같은 점 값을 눈금 사이에서 짐작해야 해요(4장 1-4-8 2회차 오케스트레이터 지적). 이때 "한 칸이 10배" 같은 캡션 주의는 맞지 않게 되니 캡션도 함께 고칩니다(1-4-8은 "두 축 모두 로그 눈금이라 같은 배율이 같은 거리로 보입니다" 뒤 R1 확정안으로 바꿈). figlib `save()`가 어긋나면 경고합니다(7장).
- 세로축(결과 값)은 점마다 값 라벨이 있으면 눈금을 점 높이에 맞추지 않아도 됩니다. 값 라벨과 같은 값의 눈금 글자가 나란히 서면 중복이니 눈금을 다른 자리로 옮겨요(1-4-8 세로 눈금 1,000만, 10억).
- 칩과 값 라벨은 눈금 글자에서 16 넘게 떨어뜨립니다. 붙으면 눈금 글자처럼 읽혀요(1-4-8 1회차 100만 칩).
- 로그 축 막대(3-1-2, 3-6-5, 3-10-3)는 막대 시작점이 0이 될 수 없습니다. 막대를 가장 작은 값보다 눈금 하나 아래(예: 1)에서 시작하고(style-guide 9.7절 쓰는 법 5), 캡션 읽는 법에 "로그 눈금"을 밝힙니다. 길이 비교가 아니라 자릿수 비교라는 점을 독자가 알아야 해요.
- 선 위 중간점을 가리킬 때는 `on_line(선, x)`를 씁니다. 로그 축에서도 화면 기준으로 보간해 점이 선 위에 놓입니다.

### 4.4 막대

해당 그림: 1-3-2, 1-8-6, 1-10-5, 1-10-6, 2-1-3, 2-2-3, 2-6-7, 2-9-4, 2-12-2, 3-3-5, 3-9-3, 3-12-3.

| 항목 | 세로 막대 | 가로 막대 |
|---|---|---|
| 고르는 기준 | 범주 이름 6자 이하, 범주에 순서가 있음(턴, 단계) | 범주 이름이 6자 초과 |
| 범주 라벨 | 축 아래(`categories`) | 막대 왼쪽 |
| 값 라벨 | 막대 끝 8 위. 정본이면 칩(`side="above", target_r=0`), 아니면 보통 글자 | 막대 오른쪽 끝 8 |
| 강조 | 메시지 막대 1개만 `color("accent")`, 나머지 `color("ink-200")` 면 | 같음 |
| 정렬 | 순서 있는 범주는 원래 순서. 순서 없는 범주는 값 크기순(큰 것 위나 왼쪽) | 같음 |
| 0 기준선 | 선형 축은 반드시 0에서 시작. 아래 축선이 0 기준선 | 왼쪽 0에 1px ink-900 세로선을 직접 그음 |
| 막대 폭 | 범주 간격의 약 0.5(`width=0.48`), 테두리 없음(`linewidth=0`) | 같음 |

- 구성 막대(1-10-6, 2-12-2, 3-12-3)는 쌓은 조각을 ink 계조로 나누고, 메시지 조각 하나만 accent로 둡니다. 조각 이름은 조각 옆 직접 라벨이에요. 조각이 4개를 넘으면 계열 상한(6.3절)에 걸리니 덜어 냅니다.
- 기준선(1-10-5의 GPU 메모리)은 `ax.axhline`을 1px ink-600 파선 `(0, (5, 3))`으로 긋고 오른쪽 끝에 보통 글자 라벨을 답니다. 🔄 값이라 칩을 달지 않고 캡션에 기준일을 씁니다.
- 막대 안 흰 글자는 막대 높이 24 이상이고 대비 4.5:1일 때만 씁니다(style-guide 6.4절).

### 4.5 산점도

해당 그림: 1-2-5, 1-9-3, 2-3-3. 모두 장난감 2차원 좌표입니다.

| 항목 | 서식 |
|---|---|
| 점 | `ax.scatter(..., s=36, linewidths=0)`, 맥락 점 ink-400, 메시지 점(질의 등) accent 1개 |
| 군집 | 개념이 다른 군집(이미지와 텍스트 등)만 개념색. 같은 개념 안의 군집은 ink 계조 |
| 라벨 | 점 옆 8, 붐비면 짧은 보조 지시선. 낱말 라벨은 12자 이하 |
| 축 | 장난감 좌표라 눈금 숫자와 격자선을 끔(`ax.set_xticks([])`, `ax.grid(False)`). 축 제목도 생략 |
| 각도(2-3-3) | 원점에서 점까지 1px ink-600 선, 각도 호는 1px. 각도 값이 정본(N3-1)이면 칩 |
| 하지 말 것 | 마커 모양으로 군집 구분, 점 크기로 세 번째 변수 표현, 군집을 둘러싼 둥근 면(예외: 가상 좌표로 개념을 보이는 산점도는 테두리 없는 옅은 중립색 면 허용, 실측 데이터 차트는 금지. 그림 1-2-5, 2026-10-18 저자 결정) |

장난감 좌표는 정본 표에 없습니다. 좌표값을 그림 소스에만 두고 캡션에 "장난감 좌표"라고 밝히는 것을 **제안**합니다. 축 눈금을 지운 이유도 같아요. 숫자가 보이면 독자는 그 값에 뜻이 있다고 읽습니다.

## 6. 세련됨: 차트에서 확인하는 기준

`design-rules.md` 9장의 12가지 판정 기준 가운데 차트에서 특히 자주 걸리는 것을 수치로 옮겼습니다.

| 기준 | 확인 방법 |
|---|---|
| 데이터 잉크 | 축선은 아래 하나, 격자선은 가로만, 막대와 칩에 테두리 그림자 없음. 지워도 뜻이 같은 선은 지움 |
| 강조 하나 | 회색조 미리보기에서 진한 덩어리가 하나만 보임. accent는 대상 1개와 칩 2개 이하 |
| 색 순서 | 강조 1개 accent, 나머지는 ink-400(선) 또는 ink-200(면). 계열이 셋(맥락 선 둘)이면 `rank=1, 2`로 ink-600 파선, ink-400 점선으로 한 단계씩 낮춤(4.2절) |
| 축 최소화 | 눈금 3~5개, 끝 눈금은 둥근 값, 소수 자릿수 통일(`fixed_decimals`) |
| 라벨 충돌 | 선 끝 라벨 기준선 간격 24 이상. 밀려서 꺾임선이 둘 이상 생기면 계열을 줄이거나 끝점 x를 어긋나게 둠 |
| 여백 | 축 영역 오른쪽에 가장 긴 라벨 폭 + 16을 남기고, 라벨이 없는 차트(막대)는 오른쪽을 넓힘 |
| 지시선 | 문장 30자 이하, 마침표 없음, 선과 칩과 보조선에서 8 이상. 점 있는 선이면 점은 데이터 점 위에만 |
| 칩과 점 | 칩의 가장 가까운 변에서 가리키는 점 중심까지 16 이하, 칩에 가장 가까운 데이터 점이 가리키는 점(4.2절, `chip` 경고) |
| 세로 변형 판 | 지시선 수와 상관없이 1-5-5.v 실측 판(360 × 368, 영역 y 128~320)을 지킴. 영역 위 빈 띠는 여백(P15) |
| 강조 한 덩어리 | accent가 선, 칩, 지시선 점으로 흩어지지 않게 칩과 지시선 점을 메시지 선의 같은 자리 가까이 모음. 둘이 떨어지면 지시선을 뺌 |

선 끝 라벨이 몰리면 순서대로 해 봅니다. 먼저 `plot` 높이를 키워 끝점 간격을 벌리고, 그래도 안 되면 메시지와 무관한 계열을 캡션으로 옮깁니다. 범례는 마지막 수단이에요(style-guide 6.4절 경우 2).

## 7. 렌더링과 lint

`save()`가 SVG 후처리 뒤 `lint()`를 돌리고, 문제가 있으면 예외를 냅니다. 경고(`UserWarning`)는 저장을 막지 않으니 실행 출력을 꼭 읽어요. 경고까지 오류로 보려면 아래처럼 실행합니다.

```bash
.venv/bin/python scripts/build_charts.py vol1-llm/ch08 --strict --png      # 장의 차트 스크립트 전부, 경고까지 오류로, 미리보기 PNG는 figures/_render/
.venv/bin/python scripts/build_charts.py vol1-llm/ch08 --check             # 실행하지 않고 SVG가 소스나 figlib보다 오래된 것만 보고
.venv/bin/python assets/charts/figlib.py lint vol1-llm/ch08/figures/*.svg
```

`build_charts.py`는 기본으로 차트(`.py`)만 모으고, `--kind all`이면 figkit 생성기(`.build.py`)와 표 그림 명세(`.yml`)까지 돌립니다. 파일 하나를 줄 수도 있어요. 스크립트를 못 쓸 때의 예비 명령은 `.venv/bin/python -W error::UserWarning vol1-llm/ch08/figures/1-8-6.py 미리보기폴더`입니다.

흔한 lint 오류(`save()` 예외)

| 메시지 | 원인 | 해결 |
|---|---|---|
| `토큰에 없는 색 #000000` | `color="black"` 같은 matplotlib 색 이름 | `fl.color("ink-900")` 등 토큰으로 |
| `선 굵기 2` | `lw=2`, `linewidth=0.8` | 1, 1.5, 2.5, 4만. 막대와 점은 `linewidth=0` |
| `글자 크기 12` | `fontsize=12`, 기본 크기 바꿈 | 14, 16, 20만 |
| `회전한 글자는 쓰지 않습니다` | `rotation=45` 눈금 | 가로 막대로 바꾸거나 범주 이름을 줄임 |
| `금지 기호` | 라벨, 대체 텍스트에 U+00B7, U+2014 등 | 쉼표, 괄호로 |
| `유니코드 첨자 남음` | 첨자를 `fmt_pow` 밖에서 직접 씀 | 첨자는 눈금(`fmt_pow`)에만. 본문 글자에는 "10의 23제곱" |
| `data-canon 없는 숫자 칩` | `chip`에 `canon` 빠짐 | 정본 ID를 넘김. 정본이 아니면 칩 대신 보통 글자 |

흔한 경고(`UserWarning`)

| 경고 | 해결 |
|---|---|
| `칩 ○에 canon이 없습니다` | 위와 같음 |
| `계열이 3개를 넘습니다`, `범주가 6개를 넘습니다` | 덜어 내거나 펼침 폭. 설계서 명세가 넘으면 수정안 |
| `선 끝 라벨이 다른 요소나 여백과 겹칩니다` | `plot` 오른쪽을 줄여 라벨 자리를 만들거나 칩 `side`를 바꿈 |
| `지시선 자리가 깨끗하지 않습니다` | `direction`, `length`, `text_side`를 직접 줌. 막대 차트는 늘 직접 줌(9장) |
| `지시선 문장이 30자를 넘습니다` | 문장을 줄임. 긴 설명은 캡션으로 |
| `칩 ○이 가리키는 점에서 ○ 떨어져 있습니다`, `칩 ○이 가리키는 점보다 다른 데이터 점에 더 가깝습니다` | `side`를 바꾸거나 `gap`을 기본 8로 되돌림. 이웃 점과 붙어 있으면 칩을 선이 지나가지 않는 반대쪽으로(4.2절) |
| `점 있는 선 그래프에서 지시선 점이 데이터 점 위에 있지 않습니다` | 점을 정본 점으로 옮기거나 지시선을 뺌(4.2절) |
| `로그 가로축 눈금(…)이 데이터 점 x(…)와 어긋납니다` | `log_axis(ax, "x", ticks=점 x 값)`. 점 있는 선의 점이 6개 이하일 때만 나옴(4.3절, 2026-10-17) |
| `머리줄 대상 이름이 16자를 넘습니다` | 명사구로 줄임 |

lint를 통과해도 끝이 아닙니다. 미리보기 세 장(컬러, `gray`, `w328`)을 직접 열어 강조가 하나인지, 휴대폰 폭에서 칩 숫자가 읽히는지 봐요(`qa-checklist.md`). `svg_to_png.mjs`는 tnum을 적용하지 않아 숫자가 Chrome보다 조금 좁게 보입니다. 칩이 많은 그림은 Chrome으로도 한 번 엽니다(`assets/charts/README.md` tnum 절).

## 8. 최소 예제: 그림 1-8-6

1권 그림 명세 1-8-6(C, "일반 모델과 추론 모델의 건당 비용 비교 막대(N8-3, 가상 단가)")을 정본 N8-3만으로 그린 세로 막대입니다. 저장소와 같은 폴더 구조에서 실행해 결과를 확인했습니다(2026-10-14). `UserWarning` 0건, lint `OK`, `data-canon` 칩 2개, 미리보기 PNG 3장입니다.

```python
"""그림 1-8-6: 일반 모델과 추론 모델의 건당 출력 비용.

명세: 1권 설계서 8장 그림 명세 1-8-6(C). 건당 비용 비교 막대(N8-3, 가상 단가)
메시지: 추론 모델의 건당 출력 비용은 일반 모델의 약 7.7배입니다
데이터: 1권 설계서 7장 N8-3(N2-3의 가상 단가, 출력 100만 토큰당 15달러)
  일반 모델 출력 300토큰 → 0.0045달러, 추론 모델 사고 2,000 + 답 300토큰 → 0.0345달러, 약 7.7배
가정값: 두 값 모두 가상 단가. 칩 왼쪽에 "가상 단가"를 둔다(style-guide 6.5절)
출처: 정본만 씀(references.yml 키 없음)
🔄: 아님

실행: .venv/bin/python vol1-llm/ch08/figures/1-8-6.py [미리보기폴더]
출력: vol1-llm/ch08/figures/1-8-6.svg (640 × 320, 세로 변형 없음)
"""
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT / "assets/charts"))
import figlib as fl  # noqa: E402

# N8-3 정본 문자열 그대로(칩 숫자와 글자 단위로 대조한다)
N83 = {"일반 모델": "0.0045", "추론 모델": "0.0345"}
LEADER = "추론 모델 출력 비용은 약 7.7배"
DESC = ("가상 단가로 계산한 건당 출력 비용을 막대 두 개로 비교했습니다. 일반 모델은 "
        "0.0045달러, 사고 토큰 2,000개가 더해진 추론 모델은 0.0345달러로 약 7.7배입니다.")

fig, ax = fl.figure("body", height=320, plot=(104, 88, 592, 264))
fl.header(fig, "그림 1-8-6", "건당 출력 비용")
fl.y_title(ax, "달러")

# 1) 축을 먼저 확정한다(칩, 라벨, 지시선은 데이터 좌표를 px로 바꿔 그린다)
fl.categories(ax, list(N83), pad=0.6)
ax.set_ylim(0, 0.04)
ax.set_yticks([0, 0.02, 0.04])
fl.fixed_decimals(ax, "y", 2)

# 2) 계열: 메시지 막대만 accent, 나머지는 ink-200 면
v = [float(s) for s in N83.values()]
ax.bar([0, 1], v, width=0.48, linewidth=0, zorder=3,
       color=[fl.color("ink-200"), fl.color("accent")])

# 3) 칩: 막대 끝 위 8. 막대 끝은 점이 아니므로 target_r=0
for i, s in enumerate(N83.values()):
    box = fl.chip(ax, i, v[i], s, unit="달러", accent=(i == 1), canon="N8-3",
                  side="above", target_r=0)
    fig.text(box[0] - 8, box[1] + 17, "가상 단가", transform=fl.px(fig), fontsize=14,
             color=fl.color("ink-600"), ha="right", va="baseline", zorder=6)

# 4) 지시선: 자동 배치는 막대를 보지 못하므로 방향을 정해 준다
fl.leader(ax, (1 - 0.24, 0.026), LEADER, direction="left", length=16)

fl.save(fig, Path(__file__).with_name("1-8-6.svg"),
        title="그림 1-8-6 건당 출력 비용", desc=DESC,
        preview_dir=sys.argv[1] if len(sys.argv) > 1 else None)
```

읽을 점

- 강조는 추론 모델 막대와 그 칩, 두 군데입니다. 일반 모델 칩은 기본 칩이라 회색조에서 강조가 하나로 남아요.
- 지시선 문장은 메시지를 줄인 것이고, 완전한 문장은 `figures.yml`의 `message`와 docstring에 둡니다. 약 7.7배도 정본 결과 문자열 그대로입니다.
- 지시선 점은 막대 오른쪽 위가 아니라 왼쪽 테두리(x = 1 − 0.24)에 찍었습니다. 막대 폭 0.48의 절반이에요.

## 9. 자주 하는 실수

- 칩, 라벨, 지시선을 축 범위보다 먼저 다는 것. 나중에 `set_ylim`을 바꾸면 칩만 엉뚱한 자리에 남습니다.
- 막대 차트에서 `leader`를 자동 배치로 두는 것. 자동 배치는 선, 칩, 라벨, 보조선만 피하고 막대는 보지 못해 문장이 막대 위에 얹힙니다.
- 정본 문자열 대신 `f"{v:.3f}"`로 칩 글자를 만드는 것. 0.0345가 0.035로 바뀌어도 lint는 잡지 못합니다.
- 곡선 위 중간값, 축 눈금, 🔄 값에 칩을 다는 것. 칩은 정본 결과 가운데 메시지가 기대는 값에만 답니다.
- 계열마다 다른 개념색을 칠하는 것. 개념이 아닌 축(온도, p, 단계)은 accent 하나와 ink 계조로 나눕니다.
- `tight_layout`, `bbox_inches="tight"`, `transparent=True`를 쓰는 것. 캔버스 크기가 바뀌거나 흰 바탕이 사라집니다.
- 범례를 습관처럼 켜는 것. 선 끝 직접 라벨이 기본이고 범례는 style-guide 6.4절 네 경우뿐이에요.
- 세로 변형을 별도 스크립트로 복사하는 것. 숫자가 두 곳에 생깁니다. 한 스크립트의 `LAYOUT`으로 나눕니다.
- `imshow`로 히트맵을 그리는 것. 래스터 이미지가 들어가 lint 색 검사를 통과해 버립니다.
- 로그 축 막대의 길이로 "몇 배"를 말하는 것. 로그 눈금에서 막대 길이는 자릿수만 보여 줍니다.
