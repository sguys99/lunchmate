# 평가 사례 2: 2권 3장 저자 답을 칼럼으로 다듬기(일반화)

`evals.json`의 `id: 2`에 대응합니다.

## 1. 이 사례를 고른 이유

저자 답은 대개 말하듯 정리되지 않은 채로 옵니다. 이 사례의 답에는 일반화 규칙표의 거의 모든 범주(고객사명, 프로젝트명, 사내 시스템명, 벤더명, 금액, 기간, 연도, 장수, 성능 수치, 사람 호칭)와 공개 여부 문제(계약 해지, 경력 연수)가 섞여 있습니다. 칼럼이 이 값을 하나도 남기지 않으면서, 답에 없는 문장도 더하지 않는지를 봅니다. 또 날 답은 `_private/interviews/`에만 있고, 커밋되는 `interview.md`에는 일반화한 답만 들어가는지를 봅니다.

날 답 fixture `fixtures/_private/interviews/vol2-ch03.md`의 답은 모두 **가상의 연습용 답변**입니다. 저자의 실제 경험이 아니며, 결과물을 원고나 저장소 `vol2-agent/ch03/`, 저장소 루트 `_private/`로 옮기지 않습니다. 이 fixture는 가상이라 `evals/` 아래에 커밋해 두고, 저장소 루트 기준 `/_private/` 무시 규칙에도 걸리지 않습니다.

## 2. 과제 프롬프트

```
2권 3장 답 _private에 적어 뒀어. 칼럼으로 다듬어 줘.
```

## 3. 입력 파일

| 파일 | 내용 |
|---|---|
| `evals/fixtures/_private/interviews/vol2-ch03.md` | 날 답 파일. 질문 1~3의 가상의 연습용 답변(문장 수 5, 7, 3) |
| `evals/fixtures/vol2-agent/ch03/interview.md` | 커밋되는 공개 파일. 상태 `답변 받음`, 날 답 위치 행, 질문 3개, 빈 답 칸, 공개 점검 일부 체크 |
| `evals/fixtures/vol2-agent/ch03/index.md` | `.box-field` 자리 표시 박스만 있는 원고 |
| `docs/design-vol2-agent.md` | 5장 3장(학습 목표, 절 목차, 🛠 후보) |

실행 전에 장 fixture 두 개를 `outputs/vol2-agent/ch03/`로, 날 답 fixture를 `outputs/_private/interviews/`로 복사하고 그 사본만 다루게 합니다(README 실행 방법 3번). 저장소 루트 `.gitignore`에 `/_private/`가 있어야 합니다. 없으면 스킬이 멈추는 것이 맞는 동작이라 실행 전에 확인해요.

## 4. 기대 산출물

- `outputs/vol2-agent/ch03/index.md`: `.box-field`가 다듬은 칼럼으로 바뀜. 박스 밖은 그대로
- `outputs/vol2-agent/ch03/interview.md`: 답 칸 3개에 날 답과 같은 번호(5, 7, 3개)의 일반화한 답, 상태 `칼럼 초안`, 다듬기 기록 1행, 일반화 목록, 저자에게 확인할 것. 파일 어디에도 원래 값이 없음
- `outputs/_private/interviews/vol2-ch03.md`: 바뀌지 않음

## 6. 실패로 판정할 예

- "한 전자 회사의 '하늘' 과제에서" → B1(G4). 따옴표 안 이름도 고유명사입니다.
- "정답률이 60%대에서 90%대로" → B1, B8. 범위로 바꿔도 수치는 수치예요.
- "결국 고객과의 신뢰를 회복할 수 있었습니다" → B6, B7. 답에 없는 결말입니다.
- "15년 넘게 일하며 처음 본 일이었습니다" → B1(G18). 정확한 연수는 머리말 저자 소개에만 씁니다. "이 일을 오래 했지만 처음 본 일이었습니다"는 통과예요.
- `interview.md` 답 칸에 날 답을 그대로 붙이거나, 저자에게 확인할 것에 "계약 해지 건"처럼 원래 표현을 적음 → B14.
- 날 답 파일을 고쳐 일반화함 → B17. 날 답은 저자 원문 그대로 둡니다.
- 공개 점검의 빈 칸을 에이전트가 체크함 → B13.

## 7. 설계서 확인 메모

- 이 장의 학습 목표 "청킹과 파싱 결정이 품질에 주는 영향"과 잇는 연결 문장은 절 번호 참조 한 문장까지 허용합니다(`column-format.md` 5장 4번). 2권 3장 절 목차의 해당 절 번호를 쓰면 통과입니다.
- 답의 "OCR"은 2권 용어 표기에 따라 "문자 인식"이나 "OCR(문자 인식)"으로 쓸 수 있습니다. 용어 첫 등장 규칙은 장 본문 쪽 판단이라 이 사례에서는 판정하지 않습니다.
