# 평가 사례 4: 2권 6.5절 대조군 (결함 없는 원고)

`evals.json`의 `id: 5`에 대응하는 사례입니다. 결함을 하나도 심지 않은 원고를 R1 전면 검수로 돌려, 스킬이 없는 문제를 만들어 내지 않는지 봅니다. 실행 방법은 같은 폴더의 `README.md`에 있어요.

## 목차

1. 이 사례를 고른 이유
2. 과제 프롬프트
3. 입력 파일
4. 원고가 맞는 근거
5. 기대 결과
6. 오탐으로 판정할 예

---

## 1. 이 사례를 고른 이유

사례 1~3은 모두 결함을 심은 원고라서, 검수자가 지적을 많이 낼수록 점수가 오르기 쉽습니다. 이 사례는 그 반대 방향을 잽니다. 근거 없이 치명이나 중대를 내면 맞는 원고가 수정 후 통과나 재작성으로 가고, writer는 고칠 필요 없는 문장을 고치게 돼요.

원고는 사례 1의 R2 판(`case1-r2-vol2-6.5.md`)에서 출발했습니다. R2에 남은 직역투 한 문장을 고치고, 100자를 넘던 단가 문장을 둘로 나누고, 해요체 두 문장을 습니다체로 바꿨습니다. 사례 1과 같은 절, 같은 프롬프트라서 "결함이 있는 판"과 "없는 판"의 결과를 나란히 비교할 수 있습니다.

## 2. 과제 프롬프트

```
2권 6장 6.5절 시험 원고 검수해 줘. 원고는 .claude/skills/reviewing-chapter/evals/fixtures/case4-clean-vol2-6.5.md야. reader 보고서는 없어.
```

사례 1 R1과 같은 문장이고 파일 이름만 다릅니다. 실행할 때는 사례 1과 같이 머리 주석 두 줄을 지운 사본을 넘깁니다.

## 5. 기대 결과

| 축 | 등급 |
|---|---|
| C | 통과 |
| F | 통과 |
| U | 통과("reader 결과 없음" 표시) |
| S | 통과 |
| L | 해당 없음 |
| G | 통과(그림 파일이 없으면 "보고"만) |
| 장 판정 | **통과**. 치명 0, 중대 0. M1은 6.5절이 최상 개념 절이 아니라 해당 없음 |

그 밖에 보고서에 있어야 할 것
- 머리의 독립성 줄, 자동 검사 재실행 표
- "reader 결과 없음"과, 그래서 장 판정이 통과여도 사이클 ⑥은 reader 검수 뒤에 닫는다는 언급(`verdict-rules.md` 5장)
- `shinn2023reflexion`은 `references.yml`이 비어 있으므로 "보고" 꼬리표. 개수에 넣지 않음
- 그림 파일(`figures/2-6-6.svg`, `2-6-7.svg`)이 없으면 "보고"

허용되는 것
- 경미 지적 몇 개(리듬, 더 나은 예시 제안 등). 판정에 넣지 않았으면 통과입니다.
- "확인 요청"이나 "설계서와 기준에 대한 제안"(예: 6.5절 비유 추가 제안). 원고 지적이 아니므로 판정과 무관해요.

## 6. 오탐으로 판정할 예

이 사례의 핵심 판정은 **치명이나 중대가 하나라도 있으면 실패**입니다. 특히 아래는 자주 나올 수 있는 오탐이에요.

| 오탐 | 왜 틀렸나 |
|---|---|
| 0.599, 0.774, 0.358, 75,000, 0.255, 0.036, 약 7배를 틀렸다고 지적 | 모두 N6-1, N6-2 정본 |
| 단가 문장에 "가정" 표지가 없다고 지적 | "가상 단가"가 숫자 바로 앞에 있음(CLAUDE.md 8장) |
| "프롬프트 캐싱"을 정의 없는 용어로 지적 | 2권 0장, 1.3절, 2.2절에서 먼저 나온 말 |
| "종료 조건"을 정의 없는 신규 용어로 지적 | 같은 문장에서 "목표를 이루면 멈추는" 조건으로 풀어 씀 |
| 비유가 없다고 중대로 지적 | 난도 지도가 비유 "없음"이고, 새 비유는 저자 승인 전 넣지 않음 |
| `shinn2023reflexion` 미등록을 중대로 셈 | 설계서 출처 표의 ✅ 키. `references.yml` 작성은 researcher 몫이라 "보고" |
| 절 검수인데 10요소, 분량, 장 도입 질문을 미충족으로 셈 | 절 검수에서는 "해당 없음" |
| 그림 파일 없음을 중대로 셈 | "보고"(SKILL.md 11장) |
| 해요체 비율이 절 단위로 15~25% 밖이라고 지적 | 18.8%로 범위 안이고, 비율은 장 파일 단위 기준 |
